# Devanshi Gaur Portfolio Site

A clean, responsive personal portfolio website for GitHub Pages.

## What is included

- `index.html` — portfolio content
- `styles.css` — responsive design and dark mode styling
- `script.js` — mobile menu, active navigation, and dark mode toggle
- `.nojekyll` — keeps GitHub Pages from trying to process this as a Jekyll project
- `github-profile-readme.md` — optional README content for your GitHub profile repository

## How to publish it on GitHub Pages

1. Sign in to GitHub as `devanshigaur7`.
2. Create a new public repository named exactly:

   ```text
   devanshigaur7.github.io
   ```

3. Upload these files to the repository root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `.nojekyll`

4. Go to repository **Settings → Pages**.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Save.
7. Your site should appear at:

   ```text
   https://devanshigaur7.github.io/
   ```
